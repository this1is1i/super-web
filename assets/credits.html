素材鸣谢

感谢创作者提供的开放素材。本主题的素材随项目保存，无需连接第三方素材站即可加载。

星球插画 · Kenney

使用 Planets 1.0 素材包中的 Planets/planet02.png，本地文件为 art/planet.png。原始图片未改动，页面使用 CSS 调整尺寸、饱和度和动效。

许可：Creative Commons Zero（CC0）。随素材提供的许可原文。

图标 · Lucide

使用 Lucide 的 lucide-static@0.468.0 SVG 图标，通过 jsDelivr 下载后本地保存。包含 orbit、settings-2、book-open、message-circle、rotate-ccw、arrow-left-right、sparkles 与 arrow-up-right。

许可：ISC，部分继承自 Feather 的图标适用 MIT。随包提供的完整许可原文。

界面与动画

棋舱面板、星空、轨道装饰、棋子样式和对局动效为本项目以 CSS 与 Web Animations API 制作。未使用角色或付费模型。
