# 白色龙娘 · V2 五官分层素材

在 V1 粗分层基础上，新增 14 个脸部素材层。完整 PSD 共 **21 层**：19 个默认可见层、1 个隐藏张口表情、1 个隐藏 V1 对照层。画布 1280 × 1664，RGB / 8 bit / 透明底。

这份文件用于继续修图、导入与绑定准备，**不是已完成绑定的 Live2D 模型**。本机没有 Cubism Editor，未做实际编辑器导入验证。

## 本轮拆分

| 部件 | 图层 | 用途 |
| --- | --- | --- |
| 脸底 | 头底与脸底 | 补全移除五官与刘海后的皮肤；头角、耳朵和后发仍在此层 |
| 前发 | 前发与刘海 | 与脸底分离，可继续做前发变形器 |
| 左右眼 | 各自眼白、虹膜、上眼睑、下眼睑，共 8 层 | 视线与眨眼绑定准备；虹膜内仍包含瞳孔和高光 |
| 眉 | 左眉、右眉 | 分别绑定表情 |
| 嘴 | 闭口微笑、张口微笑 | 两种互斥素材，张口默认隐藏；尚未分成上下唇、口腔与舌头 |

龙尾、双翼、双侧发束和身体沿用 V1 源 PNG；PSD 中已嵌入全部像素，单独使用 PSD 不需要外部 PNG。源文件的复现清单 `manifest.json` 会引用相邻的 `layers-v1` 目录，保留两个目录才能重新构建。

## 文件与预览

- `white-dragon-layers-v2.psd`：完整分层源文件。
- `composite-preview.png`：默认闭口状态的拼合图。
- `manifest.json`：从后到前的顺序、整数位置、虹膜剪贴关系与嘴形互斥分组。
- `prompts.json`：内置 ImageGen 的完整提示词集；`selected:false` 标注了未采用的右上眼睑初稿。最终使用 `lid-upper-right-corrected.png`。
- `/prototypes/white-dragon-layers.html?v=2`：图层显隐、前发隐藏检查、两种嘴形切换、深浅底及 V1 对照。

所有 PNG 保留生成器原始 RGBA，未进行程序抠图或缩放。生成式编辑没有完全锁定轮廓和比例：V2 的头部较 V1 更大，刘海及五官细节也有变化；这不是原画的逐像素精确拆分。图层已通过位置调整拼合，仍需美术精修后再作为最终绑定稿。

## 剪贴与导入注意

左右虹膜分别紧邻放在对应眼白之上，并写入 PSD 剪贴标志。网页预览也用眼白 Alpha 遮罩，因此眼球不会直接越出眼眶。到 Cubism 后应检查并建立对应 ArtMesh 的裁剪关系；不要假设 PSD 剪贴会自动成为完整的运行时裁剪设置。

切换张口时隐藏闭口层；网页已自动互斥。左右均指画面方向。原画对照层不参与建模和纹理图集。

## 尚待精修

- 小尺寸半透明边缘仍有杂色，眼睑与眼白边缘需要局部贴合修整；当前没有完成大幅转头、闭眼极限形态的露底验收。
- 虹膜高光尚未独立；闭眼还需要眼睑关键形态，不能靠这一组静止图层直接得到自然眨眼。
- 口腔、舌头、上下唇未精拆；现有两张嘴形适合先确定表情，不等同于连续口型。
- 身体/四肢、耳朵/角、前发内部发束仍需按动作需求继续拆分。
- 尚无网格、变形器、物理、动作文件、`.cmo3` 或 `.moc3`。

## 构建与验证

项目本地工具位于 `tools/live2d`。依赖已经与游戏隔离，进入该目录后：

```powershell
npm.cmd ci --ignore-scripts --no-audit --no-fund
npm.cmd test
node build-psd.js layers-v2 --preview-only
node build-psd.js layers-v2
```

打包器先读回校验画布、层数、顺序、名称、位置、显隐、剪贴标志及每层完整 RGBA 字节，随后写盘并比对文件字节。已有不同内容的 PSD 会拒绝覆盖。预览模式只更新拼合预览，不生成或覆盖 PSD。

建议绑定顺序：眼球裁剪与视线 → 上下眼睑开合 → 双眉和嘴形 → 头部角度 → 前发、侧发、翼与尾的物理。素材缺口应在网格绑定前修完，避免后续反复重做。
